# Architecture Decision Record Template

- **ADR:** `NNNN`
- **Title:** Short imperative title
- **Status:** `Proposed` | `Accepted` | `Superseded by ADR-XXXX`
- **Date:** `YYYY-MM-DD`

## Context
What architectural, platform, security, or UX constraint forces a decision?

## Decision
What exact design or permission contract do we adopt?

## Verification / Spike Criteria
What concrete tests in real Chrome 116+ / Stable must pass before this decision moves to `Accepted`?

## Consequences
Positive outcomes, trade-offs, and fallback path if verification fails.
